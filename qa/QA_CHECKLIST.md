# QA Checklist — Mini E-Commerce App

## Backend API
- [ ] GET /api/products returns all products
- [ ] GET /api/products/:id returns single product
- [ ] POST /api/cart adds item to cart
- [ ] DELETE /api/cart/:id removes item from cart
- [ ] POST /api/checkout processes checkout

## Frontend Pages
- [ ] Home/Product page loads correctly
- [ ] Cart page shows correct items
- [ ] Checkout page submits correctly
- [ ] All pages are mobile friendly
- [ ] No broken links or blank pages

## General
- [ ] App loads without errors
- [ ] All buttons work correctly
- [ ] Error messages display properly
